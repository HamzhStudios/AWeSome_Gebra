# Contributing

Thanks for taking an interest in AWeSome Gebra.

## Bug reports and ideas

These are welcome. Open an issue and include:

- What you expected to happen
- What happened instead
- The page you were on, if the problem only shows up on certain sites
- Your browser and version

Screenshots help a lot for anything visual, such as grid alignment, label crowding or panel layout.

## Security issues

Do not open a public issue for a security problem. email contact@hamzhstudios.com. And You will get a reply.

## Code contributions

Not being accepted at this time.

AWeSome Gebra is published under all rights reserved, with no open source license. That means there is no legal framework here for merging someone else's code, so a pull request cannot be accepted no matter how good it is. This is not a judgement on the work. It is a licensing position.

If you have an idea you want to see built, describe it in an issue. That is the most useful thing you can send.
